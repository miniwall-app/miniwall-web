# Changelog

## 0.1.0

First public release (2026-10-20): `<Paywall>`, `usePaywall()` and `useAutoPlacements(options)` for `@miniwall/web` 0.1, safe to server-render. `useAutoPlacements` shows the placements set to show themselves (page load, delay, scroll, exit intent) while the component is mounted.
